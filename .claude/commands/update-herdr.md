Update this herdr fork from upstream and rebuild it, following FORK_MAINTENANCE.md in this repo (it has the current toolchain notes). Do this:

1. `git fetch upstream` then `git merge upstream/master`. If there are conflicts, they're most likely in `src/integration/registry.rs` (`integration_specs()`), the `Agent`/`IntegrationTarget` enums in `src/detect/mod.rs` / `src/api/schema/integrations.rs`, `src/integration/{mod,actions,targets}.rs`, `src/cli/integration.rs`, or `src/integration/config_edit.rs`. Resolve by taking upstream's side and re-applying the Trae wiring, not by dropping it. `docs/next/api/herdr-api.schema.json` is a generated snapshot: don't hand-merge it, regenerate it afterward.
   - Watch for silent merges: `Agent::ALL` and `Agent::SCREEN_MANIFEST_AGENTS` in `src/detect/mod.rs` have explicit array lengths. When upstream adds an agent, git merges the entries cleanly but keeps one side's length. Set it to the real count.
2. Toolchain: Rust comes from rustup (`/opt/homebrew/opt/rustup/bin` on PATH), which honors `rust-toolchain.toml`. Zig comes from Homebrew (`zig` on PATH, no `ZIG` needed). Check the required Zig version in `build.rs` / `vendor/libghostty-vt/build.zig.zon`; if it changed, switch the Homebrew formula and `rm -rf vendor/libghostty-vt/.zig-cache`. If zig fails with `TlsInitializationFailed` fetching packages, download each URL with curl and run `zig fetch <file>` from inside `vendor/libghostty-vt/`.
3. Run `GIT_CONFIG_GLOBAL=/dev/null just ci 'not binary(live_handoff)'` (clippy + nextest + maintenance tests; the same filter upstream CI uses on macOS; `GIT_CONFIG_GLOBAL` isolates the tests from the global `diff.external = difft`). Run `cargo fmt` if lint only fails on formatting.
4. If `generated_protocol_schema_artifact_is_current` fails, regenerate it: `HERDR_UPDATE_API_SCHEMA=1 cargo nextest run generated_protocol_schema_artifact_is_current`, then re-run step 3.
5. If anything else fails, stop and report it; don't push past a real test failure.
6. `cargo build --release --locked`, then install by rename so the running server's binary isn't overwritten in place: `cp target/release/herdr ~/bin/herdr.new && mv ~/bin/herdr.new ~/bin/herdr`.
7. Stop here and ask before doing anything further. Restarting the herdr server (`herdr server stop && herdr`) disconnects every pane in the current session, so confirm timing with me before running it. Same for `herdr integration install trae` if `TRAE_INTEGRATION_VERSION` bumped: check first, don't run blindly.
8. If the merge went cleanly and tests pass, propose commit messages (lowercase conventional style, no AI co-author lines), then ask whether to push the updated `master` to `origin` (the fork; auth is via `gh`).
